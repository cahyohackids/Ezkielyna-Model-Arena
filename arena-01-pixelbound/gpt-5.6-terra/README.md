# PIXELBOUND: Lost Signal

Open `index.html` in a modern browser to play.

Controls: **A/D** or **arrow keys** to move, **Space/W/Up** to jump, **Shift** to dash, **R** to restart, and **Esc** to pause. Touch controls appear automatically on touch devices.

The game is self-contained: procedural Canvas pixel art, synthesized Web Audio effects, three playable levels, and browser-local progress/settings persistence.
