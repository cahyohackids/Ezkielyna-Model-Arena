# PIXELBOUND: LOST SIGNAL

An original, dependency-free 2D browser platformer built with HTML5 Canvas and procedural Web Audio.

## Run

```bash
npm start
```

Then open `http://127.0.0.1:4271`.

## Controls

- `A` / `D` or arrow keys — move
- `Space`, `W`, or Up — jump (hold for height)
- `Shift` — dash
- `R` — restart level
- `Esc` — pause

Touch controls appear automatically on touch-capable devices. Progress and settings are saved locally in the browser.
